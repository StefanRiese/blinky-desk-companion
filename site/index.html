Blinky Setup

Flash the firmware and set up a new Blinky, right from the browser. Works in Chrome or Edge on Windows, macOS and Linux. Nothing is installed, and your settings go straight to the device.

1 Install the firmware

Plug Blinky into this computer with a USB cable. Skip this step if the firmware is already installed.

Checking for firmware…

2 Connect

Close buddyd or any serial monitor first: only one program can use the USB port.

This browser can't use USB devices (Web Serial). Please use Chrome or Edge on a computer.

3 Settings

Connect the device to load its settings.

WiFi
2.4 GHz networks only. Leave WiFi empty to use the buddy only over USB.
Location
Used for weather, air quality, night hours and alarms. Place search by Open-Meteo.
Host computer (optional)
Over USB the buddy finds buddyd by itself. For a host on the network (e.g. a Proxmox container) enter auto to find it via mDNS, or its address. Empty = USB only.
Units
Only changes what the display shows. Data from the host stays metric.
Display
Touch, notifications and alarms wake a dimmed screen. At night the eyes are sleepy.
Pages
Which pages to show, in swipe order. Pages sent by a host (e.g. CI status) are added at the end. A hidden Alarm page still appears while an alarm rings.
Alarms
Sound reactions
Mood
Data sources (advanced)

What the buddy shows besides its own sensors. Each source is fetched by the device when its WiFi has internet, otherwise by buddyd. See the protocol.
