# ESP32 Desk Buddy

A desk companion with animated mood eyes, weather, indoor climate and custom data pages.
It runs standalone over WiFi, or gets its data from a host service (`buddyd`) on a laptop
(USB serial) or in a Proxmox container (TCP).
